Talk settings

Ziy's Talk is the call surface: the lobby, the room link and the controls. The meeting itself runs on a Jitsi Meet server you point it at, because Ziy does not run a call service and would rather not pretend to.

Your meeting server

Calls run on a Jitsi Meet you control. Add the address with its scheme, for example https://meet.example.org. Ziy only ever navigates you there; it does not read or write anything on that server's behalf.

An https address only: a call sends audio, video and who-is-here, so an http origin would put all three on the wire.

The public test server is a free community Jitsi Meet run by a third party. It is a quick way to see a real call. It is not private: that operator can see who joined, when, and the room name. Ziy will still warn you before every call on it.

Warnings

On by default. Ziy will say, before every call, that the meeting runs on hardware it does not control and that the operator can see who joined and the room name. Turning this off is a real decision, not a cosmetic one: re-asking every time would only train you to dismiss the warning.
